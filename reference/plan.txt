THE DECISION
1. Executive summary
More than 2,000 people applied to Wispr Flow’s India roles in the week before this challenge, and the
team says the applications were hard to tell apart: the same over-polished PDF résumés. So the format
changed. The new brief is to build the most creative portfolio of yourself, with your voice, and to show the
chances you took, the mistakes you learned from, what you care about and how you think.
Out Loud is a build-ready answer to that brief. It is a single-page interactive portfolio with three chapters and one
proof layer, built on Emergent and spoken into existence with Wispr Flow.

typing-versus-talking test with real timings.

2.3 Reading between the lines

Sameness is the enemy. The first filter is distinctiveness. A clean but conventional portfolio loses to a specific,
odd, memorable one.

It is a growth role. The page says they want people who turn creative ideas into campaigns. The portfolio should
show campaign thinking, not only engineering.

Voice is the product. They will notice whether voice shaped the work or was bolted on. Show the process, not
just the claim.

Interns need no channel history. The FAQ says interns are judged in the context of their experience. Initiative,
learning and follow-through carry the weight.

The page names formats it likes: interactive timelines, choose-your-own-path stories, simulators, quizzes and
ask-me-anything apps. Out Loud uses a timeline, a live demo and a puzzle.
2.4 Design principles
 Principle
Meaning in practice
Specific over polished
Real decisions, real numbers, real mistakes. Rough edges are acceptable; vagueness is not.
Evidence over adjectives
Every number carries a badge: verified with a source, or marked not measured.
Voice as method
Dictate the copy, the prompts and the fixes. Keep the receipts.
One scroll, three minutes
A reviewer should reach the secret and the contact link in under three minutes.
Honest by default
Proposals are labelled as proposals. Samples are labelled as samples. No invented data.

5.3 Chapter 3 · The Secret Layer (flair)
Reader question: is there something here worth coming back to? The chapter turns your steganography internship
project into a puzzle. A short message is hidden in the lowest bit of the colour values of a PNG. Visitors collect three
clues, load the image into a browser decoder, enter a short passphrase, and unlock a bonus story and your answer
to the $3,000 question.

same method.


Carrier: a lossless PNG. JPEG recompression rewrites pixel values and destroys the hidden bits. Test on the
deployed URL.

Frame: a 32-bit length, the UTF-8 message bytes, then a CRC-32 of the message, written most-significant bit first
into the lowest bit of each R, G and B byte (alpha is skipped).

Lock: an optional passphrase XOR-ed over the message. It is a puzzle lock, not security; a wrong passphrase
fails the CRC and shows a friendly message.

Decoder: runs entirely in the browser using a canvas; the image is never uploaded.

Reference code: an encoder (Python) and decoder (JavaScript) are in Appendix B and were tested for a round
trip, including wrong-passphrase handling and non-ASCII text.

encode_secret.py (offline, run once)
 """Hide a short message in the lowest bit of every R, G, B byte of a PNG.
Usage: python encode_secret.py cover.jpg secret.png "Your message" [passphrase]
"""
import struct, sys, zlib
from PIL import Image
def encode(src, dst, message, passphrase=""):
    data = message.encode("utf-8")
    crc = zlib.crc32(data)
    if passphrase:                                   # optional puzzle lock (not real security)
        key = passphrase.encode("utf-8")
        data = bytes(b ^ key[i % len(key)] for i, b in enumerate(data))
    payload = struct.pack(">I", len(data)) + data + struct.pack(">I", crc)
    bits = [(byte >> i) & 1 for byte in payload for i in range(7, -1, -1)]
    img = Image.open(src).convert("RGB")
    flat = bytearray(img.tobytes())
    if len(bits) > len(flat):
        raise ValueError("Image too small for this message")
    for i, bit in enumerate(bits):
        flat[i] = (flat[i] & 0xFE) | bit
    Image.frombytes("RGB", img.size, bytes(flat)).save(dst, "PNG")   # lossless only
def decode(src, passphrase=""):
    flat = Image.open(src).convert("RGB").tobytes()
    def read(n_bytes, offset_bits):
        out = bytearray()
        for b in range(n_bytes):
            v = 0
            for k in range(8):
                v = (v << 1) | (flat[offset_bits + b * 8 + k] & 1)
            out.append(v)
        return bytes(out)
    n = struct.unpack(">I", read(4, 0))[0]
    data = read(n, 32)
    crc = struct.unpack(">I", read(4, 32 + n * 8))[0]
    if passphrase:
        key = passphrase.encode("utf-8")
        data = bytes(b ^ key[i % len(key)] for i, b in enumerate(data))
    if zlib.crc32(data) != crc:
        raise ValueError("Wrong passphrase or damaged image")
    return data.decode("utf-8")
if __name__ == "__main__":
    encode(sys.argv[1], sys.argv[2], sys.argv[3], sys.argv[4] if len(sys.argv) > 4 else "")

decode_secret.js (browser: pass the array from canvas getImageData)
 // Browser-side decoder. `rgba` is ImageData.data from canvas.getImageData().
function decodeSecret(rgba, passphrase = "") {
  let idx = 0;                                  // position in the RGB-only stream
  const lsb = () => {
    const p = Math.floor(idx / 3) * 4 + (idx % 3);   // skip the alpha byte
    idx++;
    return rgba[p] & 1;
  };
  const readBytes = (n) => {
    const out = new Uint8Array(n);
    for (let i = 0; i < n; i++) {
      let v = 0;
      for (let k = 0; k < 8; k++) v = (v << 1) | lsb();
      out[i] = v;
    }
    return out;
  };
  const u32 = (b) => ((b[0] << 24) | (b[1] << 16) | (b[2] << 8) | b[3]) >>> 0;
  const n = u32(readBytes(4));
  if (n > ((rgba.length / 4) * 3) / 8) throw new Error("No hidden message found");
  let data = readBytes(n);
  const crc = u32(readBytes(4));
  if (passphrase) {
    const key = new TextEncoder().encode(passphrase);
    data = data.map((b, i) => b ^ key[i % key.length]);
  }
  // CRC-32 check (also detects a wrong passphrase)
  let c = 0xFFFFFFFF;
  for (const b of data) {
    c ^= b;
    for (let k = 0; k < 8; k++) c = c & 1 ? 0xEDB88320 ^ (c >>> 1) : c >>> 1;
  }
  if (((c ^ 0xFFFFFFFF) >>> 0) !== crc) throw new Error("Wrong passphrase or damaged image");
  return new TextDecoder().decode(data);
}
module.exports = { decodeSecret };
Usage: python encode_secret.py cover.jpg secret.png "Your message" passphrase. After deploying, download the
served image and confirm that its SHA-256 matches your original.
